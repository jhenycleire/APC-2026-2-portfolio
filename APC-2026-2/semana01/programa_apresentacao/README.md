# Apresentação Pessoal - OctoStudio 🐙

Este é o projeto de introdução à lógica de programação desenvolvido durante a primeira semana de aula da disciplina de APC, de modo que realizei durante a segunda semana de aula e compartilhei com os demais discientes da disciplina.

## Sobre o Projeto
O objetivo desta atividade foi criar uma apresentação interativa utilizando programação visual por blocos no aplicativo OctoStudio. O projeto explora conceitos fundamentais como encadeamento de ações e gatilhos de interação. O tempo para criação da apresentação foi de 15 minutos, o que tornou a minha apresentação bem simples.

## Como Acessar
O arquivo original do projeto está salvo neste diretório. Para visualizá-lo:
1. Baixe o arquivo do projeto disponível nesta pasta.
2. Abra-o utilizando o aplicativo OctoStudio no seu dispositivo.
